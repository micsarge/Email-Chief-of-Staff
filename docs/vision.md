# Vision

The long-term goal is to create a personal inbox operating system that helps a user manage email with less friction. Instead of treating the assistant as an opaque black box, the project should keep the user in charge of decisions while still reducing the manual burden of reviewing every message.

## Core principles
- Privacy first
- Human approval for risky actions
- Clear, explainable recommendations
- Incremental automation rather than overreach

## Example behaviors
- Summarize unread mail at the start of the day
- Suggest archiving or deleting low-value notifications
- Move newsletters and recurring messages into designated folders
- Highlight important messages that need follow-up
